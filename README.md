# Todo List

A simple project and task management app built with vanilla JavaScript, following SOLID principles.

## Features

- Create, switch between and delete projects
- Add, complete and delete tasks within each project
- Priority levels (High, Medium, Low) with color-coded indicators
- Due dates formatted with [date-fns](https://date-fns.org/)
- Data persisted locally via `localStorage`

## Tech Stack

- JavaScript (ES Modules)
- Webpack
- date-fns
- HTML / CSS
